ParkourSpotter 
A Swift-based iOS application built for the parkour community — discover, rate, and share spots, and generate optimised workout routes tailored to your time and skill level.

Note: This project was developed as a personal/academic project and is not currently available on the App Store.


About
ParkourSpotter addresses a notable gap in specialised tools for parkour practitioners. It combines user-generated content with geographic information to create an interactive platform where users can find new spots and share knowledge with the community.
The app was built using Swift and Xcode, integrates a mapping API to visualise locations, and features a custom route optimisation algorithm that maximises the number of spots visited within a given time and difficulty budget.

Features
Spot Discovery

Interactive map with markers linked to community-submitted parkour spots
Tap any marker to view full spot details including title, description, difficulty rating, and security response time

Spot Details & Community Content

View and upload images associated with each spot
Leave and read reviews for any spot
Spot difficulty and safety ratings contributed by the community

Spot Creation

Submit new spots with a title, description, difficulty level, security response time, and media uploads
Spots are pinned to the map immediately and available to the whole community

Workout Route Optimisation

Input your available time and desired difficulty level
The app computes an optimised route that maximises the number of spots visited within your constraints

Navigation

In-app navigation to any selected parkour spot

Favourites

Save spots to a personal favourites list for quick access later

User Accounts

Full account creation and login support
User-generated content tied to individual profiles
